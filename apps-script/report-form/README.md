# 報料表單 — 部署（5 步，約 5 分鐘）

> 呢個係全站**唯一**會寫嘢去伺服器嘅功能。冇佢，網站照樣運作（撳鈕唔會出現）。
> 做完之後，每張卡會多一粒「✏️ 報料」，訪客填完 → 你張 Google Sheet 多一行 → 你核對完自己改 `data.csv`。

## 1. 開一張 Sheet

1. 去 <https://sheets.new> 開一張新 Google Sheet，改名（例如「營地資料庫」）。
2. 記住你嘅 Google 帳號 —— 之後所有報料都入呢個帳號。

## 2. 貼入程式碼

1. 喺 Sheet 揀 **擴充功能 → Apps Script**。
2. 刪走編輯器入面原本嘅 `function myFunction() {}`。
3. 開 [Code.gs](Code.gs)，複製**全部**內容貼入去，撳 💾 儲存。
4. 上方函數下拉揀 **`setup`** → 撳 **▶ 執行**。
   - 第一次會問授權：**檢閱權限 → 揀你個帳號 → 進階 → 前往（不安全）→ 允許**。
   - 呢個「不安全」係 Google 對所有自製腳本嘅標準字眼，唔代表有毒；個腳本只會改你自己嗰張 Sheet。
5. 返去 Sheet，應該見到多咗一個「報料」工作表，第一行有 8 個標題。

## 3. 部署成網頁應用程式

1. Apps Script 右上角 **部署 → 新增部署作業**。
2. 齒輪揀 **網頁應用程式**。
3. 設定：
   - 說明：`報料 v1`
   - **執行身分：我**
   - **誰可以存取：任何人** ← 一定要揀「任何人」，唔係訪客送唔到
4. 撳 **部署** → 複製個 **網頁應用程式網址**（`https://script.google.com/macros/s/AKfy…/exec`）。

> ⚠️ 個網址要留住。日後改咗 `Code.gs` 要**重新部署 → 管理部署作業 → ✏️ 編輯 → 版本揀「新版本」**，
> 網址先會唔變。直接撳「部署」新開一個，網址會變，就要再貼過。

## 4. 貼落網站

開 `app.js`，搵到：

```js
const REPORT_ENDPOINT = '';
```

改成：

```js
const REPORT_ENDPOINT = 'https://script.google.com/macros/s/AKfy…/exec';
```

再跑 `npm run guard`（第 15 項會檢查網址格式）→ `npm test` → commit。

**留空 = 全站唔會出現報料撳鈕**，所以未部署好都唔會出死撳鈕。

## 5. 試一次

1. 開網站 → 隨便揀張卡 → 撳「✏️ 報料」→ 填 → 送出。
2. 應該開新分頁見到「多謝報料 ✅」。
3. 返去 Sheet，「報料」工作表應該多咗一行。

## 日常點用

- 有新報料 → 你會見到 Sheet 多一行，狀態「待處理」。
- 想即刻知 → Apps Script **專案設定 → 指令碼屬性 → 新增 `NOTIFY_EMAIL` = 你嘅電郵**，之後每單報料都會發信。
- 想一次過匯出 → Sheet 選單 **報料工具 → 匯出待處理做 CSV**（會喺你 Google Drive 開一個 CSV）。
- 改完 `data.csv` → `node build-data.mjs` → commit → 記得喺 Sheet 把嗰行狀態改成「已處理」。

## 呢個端點嘅限制（唔好當佢係安全系統）

| 項目 | 實情 |
|---|---|
| 有冇登入 | **冇**。任何人都 POST 得，包括機器人 |
| 擋唔擋得住 | 蜜罐 + 長度上限 + 10 分鐘去重，擋到業餘垃圾，擋唔到針對性攻擊 |
| 會唔會公開 | **唔會**。只寫入你自己張 Sheet，網站唔會讀返 |
| 有冇存 IP | 冇。Apps Script 收唔到訪客 IP |
| 額度 | 免費版每日 90 分鐘執行時間、20,000 次 URL Fetch —— 你嘅量用唔到 1% |
| 私隱 | 報料會存你嘅 Google 帳號。如要寫私隱政策，講明：只收集你自願填嘅內容，用作更新營地資料 |

**因為呢個端點公開，所以前端唔可以放任何 key。** 如果你日後想「只准我個網域送」，Apps Script 做唔到
（冇得設 CORS 白名單）—— 要真正鎖就要搬去 Vercel Functions + 驗證，那時就唔再係「零後端」。
